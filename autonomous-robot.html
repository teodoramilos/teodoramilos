Autonomous Robot

2022 Raspberry Pi 4 ROS LTSpice Fusion 360 Linux Git

Overview

Worked closely in a trio to design, build, and program an autonomous robot for a third-year Electrical Engineering course. The robot was tasked with navigating an unknown environment, locating and disarming six simulated mines using LEDs, guiding neutralized mines to a disposal area, and avoiding walls and fake wildlife obstacles.

The project spanned mechanical design, circuit design, software development, and systems integration. Each team member contributed across disciplines, with a focus on getting all subsystems working together reliably under time pressure.

Navigation and Control

The robot used a combination of dead reckoning and waypoint navigation to move through the environment. Dead reckoning calculated estimated position from wheel encoder data, while the Robot Operating System (ROS) provided the framework for managing sensor input, navigation logic, and motor control in real time.

All software was developed and tested on Linux, with shell scripting used to automate startup sequences and version control handled through Git. The system architecture was designed to be modular, making it possible to update individual subsystems without breaking the overall behavior.

Hardware and Electronics

The hardware platform was built around a Raspberry Pi 4 acting as the central processing unit. Motor driver circuits were designed and simulated in LTSpice before being implemented on the physical robot. The chassis and mounting components were designed using Fusion 360 and either 3D printed or cut from available materials.

A dedicated battery system was designed to power the motors and the onboard computer independently, ensuring stable voltage supply to the Raspberry Pi during high-current motor events. All wiring was carefully routed and documented to support debugging and modification during testing.
