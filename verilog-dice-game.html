Verilog FPGA Dice Game

2022 Verilog Quartus FPGA 7-Segment Display

Overview

Designed and implemented a fully functional Craps dice game in Verilog using the Quartus design environment. The project covered the full RTL design flow: from architectural planning and HDL coding through simulation, verification, and final integration onto a physical FPGA development board.

The game correctly implements the rules of Craps, managing all game state transitions through a verified finite state machine (FSM) and displaying results in real time on the physical board's 7-segment display and LED indicators.

RTL Architecture

The design was structured as a complete RTL data path with a separate FSM controller. The data path included the following components, each implemented as a distinct Verilog module:

  • Pseudo-random dice counters to simulate two fair six-sided dice rolls
  • An adder to compute the total of both dice values
  • A comparator to evaluate game outcomes against win, lose, and point conditions
  • A point register to store and hold the established point value across game rounds
  • Test logic for simulation verification of all data path components

The FSM controller managed all game state transitions, including come-out roll, point phase, win, and lose states, and coordinated the data path components appropriately in each state.

Simulation and Verification

Each module was individually simulated and verified using Quartus waveform simulation before integration. Test vectors were written to cover all corner cases in the Craps game logic, including immediate wins, immediate losses, point establishment, and subsequent point resolution.

The complete integrated design was verified end-to-end in simulation before being synthesized and programmed onto the FPGA.

Quartus simulation waveforms showing game state transitions

FPGA Integration

After simulation, the design was synthesized and programmed onto an FPGA development board. Push-button inputs were connected as the dice roll trigger, with debounce logic implemented in Verilog to prevent contact bounce from causing spurious inputs.

The 7-segment display was driven to show the current dice values, and LEDs were used to indicate the current game state and outcome (win or lose).
