Novel Intelligent Irrigation System

2018 Python 3 Raspberry Pi 3 Matlab Simulink I2C ADC GPIO

Overview

Created an award-winning smart irrigation system for the Canada-Wide Science Fair. The system was designed to make precision agriculture accessible for any plant culture by automatically managing watering, fertilization, acidity, and labor based on real-time sensor data.

The project won a National Bronze Medal at the Canada-Wide Science Fair in 2018, competing against the top student science projects from across the country.

System Objectives

The system was designed to simultaneously achieve four core agricultural objectives:

  • Conserve water by only irrigating when soil moisture levels indicated a genuine need
  • Reduce fertilizer use through targeted, sensor-triggered nutrient delivery
  • Manage soil and water acidity by monitoring pH and adjusting automatically
  • Minimize labor by automating the full monitoring and response cycle

All objectives were validated through controlled testing across multiple plant species and growth conditions, demonstrating consistent performance improvements over manual irrigation methods.

Sensor Array and Data Acquisition

The system incorporated a multi-sensor array capable of monitoring five environmental parameters simultaneously: temperature, barometric pressure, soil moisture, sunlight intensity, and pH levels. Each sensor communicated via I2C, simplifying the wiring and allowing sensors to share a common bus.

Analog sensors were connected through analog-to-digital converters (ADC) to provide digital readings to the Raspberry Pi. GPIO expansion boards extended the available input/output capacity to accommodate the full sensor suite and actuator outputs.

Control Logic and Software

The control software was written in Python 3 running on a Raspberry Pi 3. The system continuously polled all sensors and evaluated readings against configurable thresholds for each plant profile. When a threshold was crossed, the system triggered the appropriate response through relays controlling pumps and solenoid valves.

Matlab Simulink was used during the design phase to model the system dynamics and validate control logic before deployment on hardware. This simulation-first approach caught several edge cases early and reduced the physical debugging time significantly.

Amplifiers were used to boost sensor signals where necessary to ensure accurate ADC readings across the full measurement range.
