Pixel-Art Food Log Widget

2025 HTML CSS JavaScript

Overview

Created a simple pixel-art desktop food logging widget using HTML, CSS, and JavaScript. The widget was built as a personal tool to make food and symptom tracking quick, low-friction, and actually pleasant to use day-to-day.

The design uses a pixel-art visual style to make the interface feel approachable and distinct from clinical health tracking apps. Everything runs entirely in the browser with no backend or server required.

Widget interface screenshot

Food log widget interface

Features

  • Log meals across four categories: breakfast, lunch, dinner, and snacks
  • Check off common food triggers from a curated list
  • Complete a symptom checklist to record how you felt after eating
  • Export a CSV file containing all logged entries for review or analysis
